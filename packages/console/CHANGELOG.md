An event carries `projectId` and `agent`: the agent the person acted through, named beside them on everything an agent did, a task edited as a run reported. `EVENT_KINDS` gained the `project.*` kinds, and `describeEvent` no longer says "(as ...)" itself: the feed shows the agent from the event.
  - **The command.** Every command on the board works in one project: `--project <key>`, else `CONSOLE_PROJECT`, else `.skillcdn-console.json` in the working directory or above it, which the new `console use <key>` writes; `console projects` lists the projects the person may work in. `CliIo` takes a `directory` store (`createDirectoryStore` from the entry point, a memory one in tests).
  - **The default UI.** The front page lists the projects; a project's pages are under `/p/<key>` (`matchRoute`, `projectHref`, and `taskHref(key, id)` now take the key).
