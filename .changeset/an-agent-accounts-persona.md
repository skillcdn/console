An agent account has a persona the console keeps, and an avatar the package draws (ADR-0084). `GET /api/v1/agents/proposals?count=&lang=` answers a few personas to choose from, a name in the language asked for, a handle nobody has and the parts of an avatar, each from a seed; `POST /api/v1/agents` rolls the parts where none is sent; `PATCH /api/v1/agents/<handle>` keeps the name, the title and the avatar, for a supervisor. The avatar is its parts and nothing else: `avatarShapes` and `avatarSvg` draw it as SVG, `avatarPixels`, `avatarScanlines` and `pngFile` as a PNG file up to 1024 pixels a side, with no renderer but the package's own; `rollAvatar` gives the parts of a seed; `AVATAR_SET_1` is the first set of shapes, which never changes. The `Avatar` component draws an agent account's picture wherever a member is shown (`AvatarPicture`, and `AvatarSetsContext` for a console that brings shapes of its own through `createConsole`'s `persona.avatarSets`). `console agents` lists the agent accounts, `console agent <handle>` reads one, and `console agent <handle> --avatar <file>` writes its avatar as a PNG, for its profile elsewhere. The names proposed are in the language packs (`persona.names`), a spelling per language; `proposeAgents` and `PERSONA_NAMES` for whoever proposes from them.
