A new skill, `trying-a-console`, takes a person from one sentence said to a coding agent ("let me try the console on this computer") to a first task worked on the board, on one computer: the release fetched by its tag, the console started with Docker, signing in registered at GitHub with one press, the first administrator signed in, the command connected, a first project, one task taken, reported on, asked about, handed in and finished, and how it is all taken down. `docs/start.md` sends such a request there, and `deploying-a-console` points to it for one machine.
