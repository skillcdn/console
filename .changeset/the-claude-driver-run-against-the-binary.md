The `claude` driver was run against the product's binary, 2.1.321, and corrected to what it showed (ADR-0085). An `interrupt` stops the tool call under way at once: the product's own `now` waits for the call to finish, so the driver first sends the request that stops a turn, the one the product's client library sends. The runner knows when an agent is done with what it was sent: the product says each message back when it takes it (`--replay-user-messages`), and a turn is completed only when none still waits, so that a message written as a turn was ending, or the one a turn was stopped for, is not lost to a session that ends in between. "The product started." is in a transcript once and not at every turn, with the permission mode the product runs in, and says so where that is not the mode asked for; a turn that was stopped is a status and no error; a denial is said once; `manual` is a mode `runner.json` may name; the effort an account chose stays said where the product names none. The version is listed as tried, so the account's page no longer says otherwise of it. For whoever writes a driver: `DriverHost.uuid`, the ids a driver writes its messages under.
