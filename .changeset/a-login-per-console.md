The command keeps a login per console and account, and a token goes only to the console that issued it (ADR-0027). `console login` at a second console adds a login beside the first, which is the default console; `--default` marks another. `console logins` lists the consoles signed in to, never a token. `console logout` takes `--url` and `--account`. `console use` takes `--url` and `--account` and writes them into `.skillcdn-console.json` where the directory is bound to a console other than the default or to one account of several; the file never carries a secret and drops keys it does not know. Which console a command talks to is resolved first (`--url`, `CONSOLE_URL`, the directory's file, the default login) and the token is the one kept for that console alone: `--url` for a console nobody is signed in to here is refused instead of sending another console's token, `CONSOLE_URL` and `CONSOLE_TOKEN` are taken together or not at all, an address is https or this machine, and a redirect is never followed. The credentials file of before is read as one login and rewritten in the new shape; one the command cannot read is never written over.
