The console on SkillCDN 0.5: every `@skillcdn` package is taken at 0.5.1, and this is the console's 0.5.0 (ADR-0034). What a 0.5 deployment says more of a pack is passed on as every answer of a pack is, and printed by the command: the section of a document a reference's fragment names, with where to read it; in a document's outline, how many rows each heading's tables hold and how many tables and code blocks the document has; a document made from another marked as derived among what a search finds; and how a search was ranked, by identifiers and by how much of the pack is embedded. A pack's own check holds the links' fragments now (`fragment_not_found`), which the console's pack passes. A pack read from a directory is read under 0.5.1's rules: a page a read cuts ends at the end of a line, a name written with underscores is found as written, and a question about a document is answered with the document where a skill used to stand first.
