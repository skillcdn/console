The runner drives any product that speaks the Agent Client Protocol (ADR-0085): the `acp` driver, with the command that speaks it named in the desk, `"driver": "acp", "product": { "command": "<program>", "args": [...] }` in `runner.json`. The runner is the protocol's client and offers no file and no terminal of its own, so that the agent works with its own tools; a conversation is resumed or loaded where the agent can; a message that arrives in a turn is the next turn's, and the turn is cancelled for one that is to be read now; what the agent asks leave for is answered at once, allowed once, or refused where `permissions` says `deny`; `permissions` may also name one of the agent's own modes, which the session is set to, with what it still asks refused, and an agent the driver was run against is set to the mode it has for a run nobody attends where the desk names none (ADR-0091); the model and the level of thought are the session's own choices, set in a running session. A tool call's result is what the call held last, what its command printed where the agent sends that beside the protocol, or its output as data; a conversation the agent cannot go on with is said and a new one begun; why a request was refused is read from the error's message and from what it carries beside it. What an agent tells beside its work is taken as a notice and recorded as a status, and a turn the agent ends where it was refused leave is said as that. Written from the protocol's documentation, version 1, read against the types the protocol publishes, and run against two agents, the adapters that put Codex (2.6.0) and Claude Code (0.106.0) behind the protocol, on Windows: the Agents page marks any other as a version the driver was not tried with. A tool call is said once what it was called with is known, since an agent may open one before its input is whole. `product.command` also names another binary for the `claude` and `codex` drivers. For whoever builds on the runner: `createAcpDriver` and `acpMode` in `@skillcdn/console/runner`, and `args` and `version` on what a driver is made with.
