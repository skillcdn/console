What a first run of the command by an agent that had never seen it showed, mended.

- **A page of a console served over http is handed in by its address.** `console hand-in http://127.0.0.1:11199/projects/...` was refused as `url: Invalid URL`: a link is over https, and a console on one machine is served over http, so the address a take or a written page prints could not be handed in there. The console now takes a link over http where it is an address of its own (of `PUBLIC_URL`'s origin), and refuses any other in words that say so: `url: a link is over https; over http, only an address of this console is taken`. An address that is the console's to a browser and another machine's to another client, a backslash in it or a name before an `@`, is none of its own. `restArtifactInputSchema` lets both schemes through, and the console decides.
- **The rules' first line says when a take leaves them out**: `Now that they are read, a take in this session leaves them out: console take <number> --rules <mark>`, where it said "a later take", which read as the take after the next and had the rules printed twice.
- **Where the command has no skills beside it**, a build from a checkout, `whoami` and the help say so, where each named the other as the place that says where the skill is.
- `console workspace` says what `auto` means for the day a week begins on only where the week is left to it: beside a day that was chosen, `monday  (auto: ...)` read as two answers.
