The command names its version on every request, and the console holds it to the versions it takes (ADR-0025). `console` sends `user-agent: skillcdn-console/<version> (cli; ...)`; every answer of the API carries `console-version` and `console-client-range`, and `GET /api/v1/me` answers them as `console`. Before 1.0 a console takes a command from its own version on and within its minor; from 1.0 the same major and a minor within one, either way. A command outside the range is refused with `426` and `client.outdated` or `client.too_new`; it exits with `4` and prints the update command for where it is installed (for the machine, in a project, or run again from a cache, with the package manager that put it there). Within the range, a command older or newer than the console is told once a day on stderr; `console whoami` says the versions and where the command is installed every time. `createClient` takes `userAgent`; `@skillcdn/console/api` exports the `compat` module (`parseVersion`, `judgeClient`, `clientRange`, `userAgentOf`, `clientVersionOf`, the headers, and `CLIENT_POLICY`, which narrows the common rule and never widens it); a token carries `client`, the version of the command that last presented it, which `TokenList` shows with whether the console still takes it (`consoleVersion`). The package now exports its `package.json`.
