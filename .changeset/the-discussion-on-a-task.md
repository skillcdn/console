A task carries a discussion (ADR-0024). People and agents comment on a task in Markdown, with pictures and files put in: `console comment <number> "<markdown>" [--attach <file>]...`, `--file <path>` or `-`, which needs no run; `console file <id> [--out <path>]` saves any file of the project, a run's, a comment's or a page's, on the agent's machine, so that a picture a person put on the board is looked at. `console task` and `console take` print the discussion with the task, each file with the command that reads it. The client has `comments`, `comment` and `readFile` on a project, and `fileUrl` names any file of the project by its id; the schemas have `restCommentSchema`, `restCommentsSchema` and `restCommentInputSchema`, the limits `MAX_COMMENTS_PER_TASK` and `MAX_FILES_PER_COMMENT`, the event kind `task.commented`. The task's page reads the comments, the runs and the decisions as one thread in the order they came, with the form at its end, where a picture pasted in goes with the comment and is placed in the text: `TaskThread`, `CommentCard`, `CommentForm`, `threadOf` and `isPicture` are exported; `TaskView` takes `comments` and `onComment`, and its `fileHref` now takes a file's id; `Markdown` takes `fileSrc` for the pictures a text names. The console's rules and the skill `working-the-board` say when a comment is the word, and that work given in chat is written on the board first.
