The windows of an agent account's allowance are shown in one order: the short one first, then the week, then the week of a model, on the agents' list, on an account's page and by `console agent <handle>`. A window that reset is said again after those that did not, and moved to the end of the list. `usageStanding` answers the windows in that order, by their names, and takes windows that carry a `name`.
