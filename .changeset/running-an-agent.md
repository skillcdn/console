The skill `running-an-agent` ships with the command: how an agent account is set up on a machine of its own and kept running, for the three who have a part in it. The administrator makes the account and its invitation; the operator prepares the machine, the OS account and the product's sign-in; the agent makes the machine its own from one line and works its onboarding task; its manager reads what to do when it stopped, was refused, failed or is not heard from. It carries the manifest of the app that wakes an agent at Slack. `working-the-board` says what differs for an agent account, a signal's header, whom it asks and that it never waits at a terminal, and the console's own rules say what instructs one: a supervisor's tell, the board's tasks and decisions, and the rules. The guide of a setup names the skill.
