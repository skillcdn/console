`console agent setup` ends, on a Mac, with the settings of the machine that would leave the agent unheard once nobody is there, each in a line with what to change and what the change costs: a sleep when idle, no start after a power failure, a restart the OS account is not logged in after (FileVault on, which logs no account in by itself, or the one automatic login macOS has being nobody's or another account's, as where several agents share a machine), and updates of macOS that install themselves and restart for it. The settings are read as any account may read them and none is changed; a machine that comes back by itself is told nothing more. The sentence "turn on automatic login", which a Mac with FileVault could not follow, is said on Windows alone. The skill `running-an-agent` says the same of preparing a machine.
