# A review

A task whose run finished or failed is up for review, and the verdict is a person's, never the agent's own. Told that it passes: where the run's summary named something left, a change not committed, a check not run, say what is left before closing; then, on their word, `console task edit <number> --state done`. Told to drop it: `--state dropped`. Told that more is wanted: write what is wanted as a comment on the task, what the person said as theirs and anything you add marked as your own, and take the task again; where someone else will take it, set it `ready` instead.
