# A run open on the task

Taking the task ends that run as taken over, whoever's it is. Your person's own, from an earlier session or another of their agents: do not take the task again, go on with that run. `console run <id>` reads what it reported, what it handed in and the decision it waits for; `console rules` reads the rules, which no take prints this time; a decision it waited for that is answered is acted on as phase 4 says, its outcome written; one that still waits is told to the person at once, with where the work stands and whom it waits for, and is not waited for at the terminal. Where a command on the run finds no run of this sign-in's (`run.none`), the run was begun through another of the person's agents or sign-ins: name it, `--run <id>`. Another person's: their agent may still be at it, and the console cannot tell. Say so in chat, with whose it is and when it was last heard from, and take the task only on your person's word.
